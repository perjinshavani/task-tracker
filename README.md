# Task Tracker

## Om projektet

Task Tracker är en uppgiftshanteringsapplikation byggd med TypeScript.
Projektet gör det möjligt att skapa, hantera och organisera uppgifter på ett enkelt sätt.

## Funktioner

- Lägga till nya uppgifter
- Markera uppgifter som klara
- Ta bort uppgifter
- Filtrera uppgifter
- Spara uppgifter med Local Storage

## Tekniker

- HTML
- CSS
- TypeScript
- Local Storage
- Git & GitHub

## Det här har jag lärt mig

Genom projektet har jag lärt mig att arbeta med TypeScript, skapa funktioner för att hantera uppgifter,
använda Local Storage för att spara data och strukturera kod i olika moduler.
